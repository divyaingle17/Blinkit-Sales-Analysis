# 🛒 Blinkit Sales Analysis | Power BI Dashboard

## 📌 Project Overview
An interactive Power BI dashboard analyzing Blinkit's sales performance across 
outlets, product categories, and locations to support data-driven decision-making.

## 📊 Dataset
- **Source:** Kaggle (Blinkit Grocery Dataset)
- **Records:** 8,500+ products
- **Total Sales:** $1.2M+

## 🎯 Key Insights
- Supermarket Type1 outlets contribute highest revenue (~$787K)
- Tier 3 locations drive the highest sales share (~$472K)
- Medium-sized outlets generate maximum sales ($507K)
- Fruits & Snack Foods are top-selling item categories
- Average customer rating: 3.9 across all outlets

## 🛠️ Tools & Techniques Used
- **Power BI** — Dashboard creation & visualization
- **Power Query** — Data cleaning & transformation
- **DAX** — Calculated measures (Total Sales, Avg Sales, Avg Rating)
- **MS Excel** — Raw data preparation

## 📈 Dashboard Features
- KPI Cards (Total Sales, Avg Sales, No. of Items, Avg Rating)
- Interactive Filters (Outlet Type, Outlet Size, Item Type)
- Fat Content Analysis (Low Fat vs Regular)
- Outlet Establishment trend (time-series)
- Outlet Size & Location breakdown
- Item Type wise sales comparison
